# Liquid Glass Background

Анимированный WebGL-фон со «жидким стеклом»: капли стекают по экрану, сливаются, оставляют следы и преломляются через шейдер стекла (Worley-шум).

Стек: **Vue 3 + Three.js + Vite**. Компонент самостоятельный — рендерит только фон, никакого UI.

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # прод-сборка в dist/
npm run preview  # локальный просмотр сборки
```

## Структура

```
src/
  App.vue                        # физика капель: спавн, движение, слияние, следы
  components/BackgroundLayer.vue # Three.js-рендерер, 3 прохода
  style.css                      # базовые стили и локальный шрифт Inter
  main.js
```

Рендер идёт в три прохода:
1. **Метаболы** — 18 плывущих красно-зелёных пятен на 60-секундном цикле.
2. **Стекло** — рефракция предыдущего прохода через Worley-шум.
3. **Капли** — SDF-форма капель поверх (линза, хроматика, мягкий край).

Все шейдеры встроены строками в `BackgroundLayer.vue`.

## Требования

Любой браузер с WebGL1. При его отсутствии включается Canvas2D-fallback.
